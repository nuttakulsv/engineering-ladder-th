## ก่อนวันแรก (หัวหน้า)

- [ ] เครื่องและบัญชีพร้อม: email, chat, repo, cloud, VPN, เครื่องมือจัดการงาน
- [ ] เลือก buddy และนัดคุยวันแรก
- [ ] เตรียมงานแรกที่เล็ก มีคุณค่าจริง และขึ้น production ได้ภายในสัปดาห์แรก
- [ ] แจ้งทีมว่าใครจะเข้ามา เริ่มเมื่อไหร่ ทำอะไร

## สัปดาห์แรก

- [ ] คุยกับหัวหน้าเรื่องความคาดหวัง 30 / 60 / 90 วัน
- [ ] รันโปรเจกต์บนเครื่องได้ จดจุดที่ติดไว้ทุกจุด
- [ ] แก้เอกสาร setup จากจุดที่ติด
- [ ] เปิด PR แรก
- [ ] ส่งงานแรกขึ้น production
- [ ] รู้จักทีมที่ทำงานด้วยบ่อยที่สุด อย่างน้อยหนึ่งคนต่อทีม
- [ ] อ่าน ADR และ postmortem ล่าสุดของทีม

## เดือนแรก

- [ ] ทำงานขนาด bug และ feature เล็กได้เอง
- [ ] นั่งดูคนอยู่เวร on-call อย่างน้อยหนึ่งวัน
- [ ] 1:1 กับหัวหน้าทุกสัปดาห์
- [ ] ครบ 30 วัน: ถามคนใหม่ว่าอะไรใน onboarding ควรแก้

## เดือนที่สองถึงสาม

- [ ] ทำ feature ขนาดกลางได้
- [ ] อยู่เวร on-call โดยมีคนสำรอง
- [ ] ครบ 90 วัน: ทบทวนความคาดหวังที่ตั้งไว้ตอนวันแรก และตั้งเป้าการเติบโตจาก ladder

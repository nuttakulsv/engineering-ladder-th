# ปรับใช้กับบริษัทของคุณ

ladder นี้เขียนมาให้แก้ได้ เนื้อหาทั้งหมดอยู่ใน `data/ladder.json` ไฟล์เดียว เว็บประเมินตัวเองกับเอกสารใน `ladder/` สร้างจากไฟล์นี้

## ขั้นตอนแบบเร็ว

1. fork repo นี้ หรือกด Use this template บน GitHub
2. แก้ `data/ladder.json` เปลี่ยนชื่อระดับ ตัดหรือเพิ่มพฤติกรรม
3. รัน `npm run build` แล้วเปิด `_site/index.html` ดู ถ้าข้อมูลขาดหรือผิดรูปแบบ คำสั่งนี้จะบอกว่าช่องไหน
4. เปิด GitHub Pages ใน repo ของคุณ workflow ที่มีให้จะ deploy เว็บให้เอง

กฎของไฟล์ข้อมูล: ทุกระดับต้องมีครบทุกมิติ แต่ละช่องต้องมีพฤติกรรมอย่างน้อย 2 ข้อ และมี `notYet`, `evidence`, `growth` อย่างน้อยอย่างละ 1 ข้อ id ของระดับและมิติต้องไม่ซ้ำกัน

ถ้าคุณเพิ่ม ลบ หรือสลับลำดับพฤติกรรม ลิงก์ผลประเมินที่เคยแชร์ไว้จะใช้ไม่ได้ เว็บจะแจ้งแทนการอ่านค่าผิด ส่วนการแก้คำผิดในข้อความไม่กระทบลิงก์เดิม

## สตาร์ทอัพ 10–30 คน

- ใช้แค่ L1–L4 กับ M1 ก็พอ ยังไม่ต้องมี L5 หรือ M2
- อย่าเพิ่งทำ calibration แบบเต็ม ให้ CTO หรือหัวหน้าคนเดียวอ่านผลประเมินทั้งหมดเพื่อให้มาตรฐานตรงกัน
- ใช้ ladder เป็นหลักในการคุยเรื่องการเติบโตมากกว่าการประเมิน ช่วงนี้คนเปลี่ยนบทบาทบ่อย
- ระวังการตั้งชื่อตำแหน่งใหญ่เกินขอบเขตจริง ดู [ระดับกับชื่อตำแหน่ง](levels-and-titles.md)

## บริษัท 100–300 คน

- ใช้ครบทุกระดับ แยกสาย IC กับ Manager ให้ชัด และมีกระบอกเงินเดือนของสองสายที่เทียบกันได้
- ทำ calibration ข้ามทีมอย่างน้อยปีละครั้ง
- เพิ่มพฤติกรรมที่เฉพาะกับบริษัท เช่น ถ้าบริษัทอยู่ในกลุ่มที่ต้องทำตามกฎระเบียบ เช่น การเงิน ให้เพิ่มเรื่องการปฏิบัติตามข้อกำหนดในมิติความเป็นเจ้าของ
- แยกสายเฉพาะทางได้ถ้าจำเป็น เช่น data หรือ security แต่ให้ใช้มิติเดียวกัน เพื่อให้เทียบระดับข้ามสายได้

## จับคู่กับเงินเดือน

เราตั้งใจไม่ใส่ตัวเลขเงินเดือนใน repo นี้ เพราะต่างกันมากตามอุตสาหกรรม ขนาดบริษัท และเมือง ตัวเลขที่ล้าสมัยทำความเสียหายมากกว่าไม่มีตัวเลข สิ่งที่แนะนำคือ

- ทำกระบอกเงินเดือน (salary band) หนึ่งกระบอกต่อหนึ่งระดับ กว้างพอให้คนเติบโตในระดับเดิมได้หลายปี
- ให้กระบอกของระดับติดกันซ้อนทับกันบ้าง คน L3 ที่ทำงานมานานและเก่งมาก อาจได้เงินเดือนมากกว่า L4 ที่เพิ่งเลื่อนขึ้นมา
- อ้างอิงข้อมูลตลาดจากผลสำรวจเงินเดือนของบริษัทจัดหางานหรือแหล่งที่เชื่อถือได้ และทบทวนทุกปี
- ตัดสินใจว่าจะเปิดเผยกระบอกให้พนักงานเห็นแค่ไหน การเปิดเผยระดับและกระบอกเงินเดือนช่วยลดความรู้สึกไม่เป็นธรรมได้มาก แม้จะไม่เปิดเงินเดือนรายคน
